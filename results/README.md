# Results

`baselines.md` and `baselines.csv` are generated by `uv run python -m ml.run_baselines`.
This file explains them (test week 23–30 October 2026, 266 stations, ~178,000
pairs per horizon).

## The model to beat in Phase 4: `unchanged`

| Subset | 15 min | 30 min | 60 min |
|--------|--------|--------|--------|
| All hours | 0.221 | 0.394 | 0.669 |
| Daytime (07–21) | 0.325 | 0.571 | 0.956 |
| Weekday rush | 0.588 | 1.012 | 1.667 |

MAE in bikes. Phase 4 should report the same three subsets and aim to beat
`unchanged` above all in weekday rush at 30 and 60 minutes, where the error is
largest and a user needs the forecast most.

## What the results mean

- **"Unchanged" is hard to beat.** Most 15-minute intervals do not change, so
  predicting the current value is right most of the time. The error grows with
  the horizon and is 2.7 times higher in weekday rush than overall.
- **"Same time last week" is far worse (MAE about 4.3 at every horizon).** The
  *level* at a station differs a lot from one week to the next: bikes are
  redistributed by trucks and the fleet shrinks during the period. Its error is
  the same at every horizon because it ignores the current value. The weekly
  pattern lies in how the number *changes*, not in the level.
- **"Current value + mean change" loses to "unchanged" except at 60 minutes in
  weekday rush (1.627 vs 1.667).** Each station × weekday × time cell has only
  2–3 training examples, so the averages are mostly noise. The small gain where
  changes are largest shows there is a real, predictable daily pattern. A model
  that pools examples across stations and times, such as gradient boosting with
  time features, should be able to use it.
- **Docks can be derived from bikes.** bikes + docks equals the nominal capacity
  in only 25.6 % of rows (usually it is lower, probably because of bikes or docks
  out of order), and no station has a constant sum. Deriving docks from the
  *current* total still gives docks MAE equal to or slightly below bikes MAE, so
  predicting bikes only is enough.
- **5 stations were frozen during part of the test week** (430, 473, 625, 4552,
  5424) and those pairs are excluded. Of all pairs in the test week, 0.7 % were
  removed by the frozen rule, 0.9 % by the inactive rule and 0.3 % by gaps.

## Limitations

- One test week: one unusual day can move the numbers. No weather yet.
- Only October data, with a shrinking fleet.
